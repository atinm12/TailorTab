What it does

Ordered by what makes it powerful.

The Agent

Sources any API on demand

Ask for something it was never hardcoded to do — like live ISS tracking — and the AI agent finds a public API, calls it, and renders it as a widget.

Natural language

One prompt, many widgets

"Steelers news, AAPL and TSLA prices, weather in Pittsburgh" becomes three separate widgets, laid out automatically.

Live data

No API keys needed

Stocks, news, weather, and crypto stream in live — no sign-ups or keys. The complexity is handled on the backend.

Profiles

Tailored dashboards in one click

Finance Bro opens with a live watchlist and market charts. Athlete, Techie, Newspaper, Local, and more — each ready instantly.

Personalization

Yours, and it stays that way

Widgets persist across every new tab. Customize the clock, fonts, timezone, and rotating backgrounds in a clean dark UI.

Install it (load unpacked)

While the Chrome Web Store listing is under review, you can run TailorTab locally in a couple of minutes.

Clone the repo

Download the code from GitHub.

git clone https://github.com/atinm12/TailorTab.git
cd TailorTab

Install dependencies & build

Requires Node.js. This produces the dist/ folder.

npm install
npm run build

Open Chrome extensions

Go to chrome://extensions and turn on Developer mode (top-right toggle).

Load unpacked

Click Load unpacked and select the dist/ folder inside the project.

Open a new tab

That's it — TailorTab now powers your new tab page. Type what you want to see, or pick a profile.
