[06] Run it

Load unpacked. Two minutes.

The Web Store listing is in review. Until then, run it locally — it's quick.

$ 01

Clone

Pull the source from GitHub.

git clone https://github.com/atinm12/TailorTab.git
cd TailorTab
$ 02

Build

Needs Node.js. Outputs the dist/ folder.

npm install
npm run build
$ 03

Open extensions

Go to chrome://extensions and enable Developer mode (top-right).

$ 04

Load unpacked

Click Load unpacked and select the dist/ folder.

$ 05

Open a new tab

Done. Type what you want, or pick a profile.

[07] Questions

The short answers.

Q1 Is it free?+
Yes. TailorTab is free and the source is public on GitHub.
Q2 Do I need API keys?+
No. Stocks, news, weather, and crypto work out of the box. The OpenAI key that powers the agent lives on the backend — never on your machine.
Q3 Is my data private?+
Your widgets and preferences are stored locally in your browser. The agent fetches data sources client-side, so your choices stay on your device.
Q4 What can the agent actually fetch?+
Public APIs across the open web. If the data exists and is reachable, the agent can source it and shape it into a widget — even sources it was never hardcoded for.
Q5 Why load unpacked instead of the Web Store?+
The Chrome Web Store listing is in review. Loading unpacked runs the exact same build today — no waiting.
